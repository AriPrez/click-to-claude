# Demo assets

- `click-to-claude.png` is an original generated application icon.
- `demo-medical-heart.png` is a synthetic, generated educational illustration.
  It contains no patient data and must not be used as an anatomical or clinical
  reference.
- `product-overview.png`, `precision-pin-medical-demo.gif`, and
  `precision-pin-medical-demo.mp4` are captures of the real application running
  the deterministic scene in `scripts/demo_scene.py`.

Run `scripts/record_demo.sh` to reproduce the product media inside an isolated
virtual X11 display. The recording process does not capture the host desktop.
