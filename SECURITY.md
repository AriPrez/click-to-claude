# Security policy

## Supported versions

Security fixes are provided for the latest published release.

| Version | Supported |
| --- | --- |
| 0.3.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do not disclose vulnerabilities, private captures, credentials, or
browser-profile data in a public issue.

Use **Report a vulnerability** in the repository's Security tab. Include:

- the affected version and desktop/session type;
- the smallest reproducible sequence;
- the expected and observed security boundary;
- sanitized logs or diagnostics;
- a suggested mitigation, if known.

If private vulnerability reporting is temporarily unavailable, open a public
issue containing no exploit or private data and ask the maintainer to establish
a private contact channel.

Reports concerning window verification, clipboard isolation, temporary capture
cleanup, redaction export, or the dedicated browser profile are especially
important. You should receive an initial acknowledgement within seven days.
